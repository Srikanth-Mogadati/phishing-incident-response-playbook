# SOC Incident Response Playbook Series

This directory organizes a month-by-month defensive SOC portfolio series following the initial **Phishing Incident Response Playbook (December 2024)**.

| # | Portfolio month | Playbook |
|---|---|---|
| 01 | December 2024 | [Phishing Incident Response](../README.md) |
| 02 | January 2025 | [Brute-Force / Failed Login Investigation Playbook](./02-brute-force-failed-login/README.md) |
| 03 | February 2025 | [Malware Detection & Response Playbook](./03-malware-detection-response/README.md) |
| 04 | March 2025 | [Suspicious PowerShell Investigation Playbook](./04-suspicious-powershell/README.md) |
| 05 | April 2025 | [Impossible Travel / Suspicious Login Playbook](./05-impossible-travel-suspicious-login/README.md) |
| 06 | May 2025 | [Ransomware Incident Response Playbook](./06-ransomware-incident-response/README.md) |
| 07 | June 2025 | [Account Compromise / Credential Theft Playbook](./07-account-compromise-credential-theft/README.md) |
| 08 | July 2025 | [Malicious URL / Domain Investigation Playbook](./08-malicious-url-domain/README.md) |
| 09 | August 2025 | [Data Exfiltration Investigation Playbook](./09-data-exfiltration/README.md) |
| 10 | September 2025 | [Privilege Escalation Investigation Playbook](./10-privilege-escalation/README.md) |
| 11 | October 2025 | [USB / Removable Media Investigation Playbook](./11-usb-removable-media/README.md) |
| 12 | November 2025 | [Insider Threat Investigation Playbook](./12-insider-threat/README.md) |

Each playbook contains a Mermaid investigation flowchart, triage checklist, evidence guidance, sample Splunk SPL, Microsoft Sentinel/Defender KQL, containment considerations, an incident-ticket template, and MITRE ATT&CK context.

> Dates above are portfolio timeline labels. GitHub repository and push timestamps remain independently observable.
